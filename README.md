# Summary
General 3D point cloud prediction model from previous LidDrivenCavity Model.

# Instructions
- Do pip install -r requirements.txt
- Run train.py
    - Note: this will automatically download the dataset csv files required (openFoam 1e-3).
    - If you don't have an internet connection, you will need to add the Data folder manually from
        https://drive.google.com/file/d/1h66tx2eT9lZk1wWf3IeEpBBMs7xq-Wth/view?usp=drive_link
- Run evaluate.py
